# 订阅额度开发流程需求

## 原始需求

用户只有 ChatGPT / Codex 订阅额度，没有 API 账单预算，要求执行调整：把模型开发和审查移到本地 Codex，保留 GitHub CI 与部署，使用聊天审批后合入。

## 范围

- 停用依赖 OpenAI API 密钥和 GitHub App 的云端开发 / 合入工作流。
- 日常入口为当前 Codex 聊天；分析、方案、代码、测试和 PR 由代理完成。
- hxshen97 在聊天中批准具体 PR 当前提交后，代理重新检查版本、CI，再通过已连接 GitHub 工具合入。
- 保留六模块、中英文版本、所有原始内容及现有验收检查。
- 本次调整需新 PR 审批；之前对 PR #1 的批准不授权本次合入。

## 验收

| 编号 | 条件 | 验证 |
| --- | --- | --- |
| R1 | 活跃 Actions 只执行 CI / 部署，不调用模型或要求 API / App 密钥 | 工作流测试与 actionlint |
| R2 | 文档一致描述本地订阅登录、聊天审批和额度限制 | 文档审查与配置测试 |
| R3 | 未审批、旧提交审批、CI 失败不能合入；本人创建 PR 可以聊天审批 | 新聊天审批策略测试 |
| R4 | 原有六模块、双语、内容和功能不变 | npm run verify 与 PR CI |

## 不在本次范围

创建 API 账单、注册 GitHub App、添加定时任务、迁移既有依赖或修改主页内容。
