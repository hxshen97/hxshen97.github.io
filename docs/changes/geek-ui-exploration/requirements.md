# 需求与验收

## 原始需求

需求：新建分支尝试新风格的UI。从网上搜索10个geek风格的ui设计，给出风格示例让我挑选，要求使用前段设计优化插件，有大量动画效果，针对当前个人主页重构，技术栈可修改

## 范围与合理假设

### 2026-10-15 补充需求

用户进一步授权：“技术栈的选择可以更加现代，一切为了服务更好的动画效果”。本轮在试验分支将现代动画层接入真实双语首页，而非继续只画概念图。保留 Astro 内容与静态路由，采用 React 19 + React Three Fiber 9 / Three.js、React Postprocessing、GSAP。新增 GPU 点云形态变换、辉光、镜头与滚动联动，保持 03 的左右阅读层次。首页之外的模块功能与路由继续兼容，本轮不迁移个人数据或内容 schema。技术选型是常规实现判断，不另设人工审批；不会自动合入或部署。

用户反馈：“没有完全满意，只有03的阅读布局合理，我希望拥有更加酷炫的动画效果”。保留 03 左侧身份/导航、右侧内容的阅读结构，新增可操作的强化动画预览，不把上一轮十个示意卡片当成最终 UI。预览提供三种可切换的空间图形：流场、轨道、晶格；指针旋转、点击脉冲、滚动景深与项目聚焦都可实际体验。保持文字稳定，不把正文阅读绑定在动画进度上。用户尚未选定最终视觉，因此继续在本分支探索，不替换生产站。

本阶段创建 codex/geek-ui-exploration 分支，调研十个真实网站，提供独立的动态概念选型板。用户明确要求先挑选风格，因此网站实现与技术栈迁移等待风格选择，不预先替用户决定。概念板为原创示意，不是参考网站截图，也不是已完成的主页重构。

使用官方 anthropics/skills 的 frontend-design 技能，安装到项目 .agents/skills/frontend-design。MagicPath 外部设计插件已找到并建议安装，尚未确认连接，不能声称已调用。
