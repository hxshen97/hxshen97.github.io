# 实施方案

## 第三轮：现代 GPU 动画接入真实首页

选择 Astro 5 + @astrojs/react 4.x（与现有 Astro 5 兼容），React 19 + React Three Fiber 9（官方配对），Three.js 着色器粒子、React Postprocessing 辉光，以及 GSAP/ScrollTrigger 镜头编排。R3F 10 当前仍为 alpha，本轮不以实验性 WebGPU 渲染器作为唯一路径；稳定 WebGL2 已可实现目标视觉。

动画组件延迟加载独立 3D 场景模块，内容、真实头像、CTA 和六模块仍由 Astro 静态输出。粒子在 GPU 顶点着色器中由环面结、轨道、波面三种坐标变形；仅传时间/视角等少量 uniform。Bloom 增强高亮点，GSAP 驱动形态插值和 ScrollTrigger 镜头推进，不强制平滑滚动或阻止浏览器滚动。场景使用 demand 帧调度，只有可见、页面前台、未暂停且非减弱动画时请求下一帧。低端/移动端减少粒子和关闭昂贵后处理；无 WebGL2 或上下文丢失显示 CSS 静态图形，保留阅读和导航。错误边界覆盖场景创建失败。

范围：共享 HomePage 接入动画岛与深色阅读布局，主页侧栏使用专门的深色布局样式，不改变其他六模块的内容管理。新文案全部同步 ui.ts。旧首页入场与正文揭示继续保留原生浏览器动画以维持既有可访问性门禁；GSAP 负责 3D 编排，避免两套工具争夺相同 DOM 属性。

引用：[R3F 版本配对](https://r3f.docs.pmnd.rs/getting-started/introduction)、[Astro React 集成](https://docs.astro.build/en/guides/integrations-guide/react/)、[Bloom](https://react-postprocessing.docs.pmnd.rs/effects/bloom)、[GSAP ScrollTrigger](https://gsap.com/docs/v3/Plugins/ScrollTrigger/)。

## 第二轮：03 阅读骨架与空间动效

2026-10-15：新增 motion-study.html，独立双语交互原型。延续 frontend-design 指导，主体为左侧固定身份/目录，右侧大幅交互图形与正常纵向阅读。以真实姓名、现有职业文案、一个项目、三篇论文及博客空状态做内容校准，简历链接进入现有生产站；不宣称这份概念覆盖完整简历内容。

布局草图：`[姓名 / 职业 / 导航 / 联系] | [交互空间图形 → 项目 → 论文 → 博客 → 联系]`。左对齐文字，桌面 300px 身份区、弹性内容区，手机顺序堆叠。字体：Bahnschrift/Segoe UI 的技术感无衬线正文，Consolas 仅用于图形控制与项目技术标签。配色：空间 #080d18、面板 #101a2b、正文 #e8eef9、次要文字 #98aac3、冰蓝 #74d9ff、紫色 #a899ff。动画集中于可操作图形；可见信息不依赖 canvas。

相比第一轮修改：舍弃重复小卡片，给空间图形足够面积与景深；保留稳定阅读骨架。Canvas 投影点云可在流场、轨道、晶格之间变形。指针影响视角，按钮/点击触发向外脉冲，滚动改变空间转角与深度。项目用局部倾斜与光场强调焦点，论文保持正文可读。所有动画有暂停与系统减弱动画支持；图形离屏、页面隐藏时停止调度，手机减少点数并限制刷新率。不增加框架依赖，后续确定后再抽为 Astro 组件。

## 问题与目标行为

现有 Astro 5 首页为 Apple 风格，共享 HomePage.astro 消费双语字典和内容集合。本阶段通过独立 HTML 对比终端、HUD、工程作品集、复古桌面、游戏、3D、产品实验室与工业仪器风格，让用户选择后再设计全站。

## 模块与数据变化

不改生产页面、内容集合、路由或依赖。选型板只使用账号 hxshen97、现有模块名及概念图形，不编造履历、论文或项目数据。参考链接、对本站的动画建议与实现成本明确分开。图形用 HTML/CSS 原创绘制，不复制原站素材。

## 实施步骤

1. 创建试验分支；搜索原站，安装并阅读官方 frontend-design 技能。
2. 生成十种配色与布局明显不同的概念图；用扫描、轨道、窗口、横版角色、伪 3D 等动画表达方向。
3. 提供统一暂停开关与 prefers-reduced-motion 支持，移动端单列展示。
4. 用户选定主风格及辅助方向后，更新本方案并实施主页和六个双语模块。

## 技术方向与风险

选型板使用两列比较，手机单列；中文正文为系统字体，终端/HUD 示意使用 Consolas 等宽字体，阅读页概念使用系统无衬线字体。个人身份与六模块入口是核心图形内容。

这十种方向刻意区分信息结构与视觉材料，避免只把同一套卡片换颜色。正式站点动画应响应操作或滚动；概念板持续循环仅便于比较，提供统一暂停。

优先评估 Astro 静态页面配合动画增强。大量动效不自动要求换框架；全场景 3D 才考虑 Three.js 或 React 岛。这里的依赖建议是后续评估方向，未安装、未验证兼容性。HUD、游戏和全屏 3D 的移动端成本较高，应保留正常导航、文字正文和减弱动画模式。动画用于首页与作品展示，正文避免持续扰动。GitHub Pages 静态部署、尾斜杠和原有内容能力继续作为约束。
