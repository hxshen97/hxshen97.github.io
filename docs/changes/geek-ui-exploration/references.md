# Geek UI 风格参考

调研日期：2026-10-14。下列风格名称、适配建议和成本为本项目的设计判断。概念板不是原站截图；动画栏是拟用于本主页的效果，不代表原站均有这些动画。

| 编号 | 风格与真实参考 | 针对本站的视觉方向 | 拟采用动画 | 成本与适配 |
| --- | --- | --- | --- | --- |
| 01 | [终端：M4TT72](https://term.m4tt72.com/) | 等宽命令提示、目录式模块、深色文字界面 | 打字、光标、命令展开、输出滚动 | 中；geek 感强，但保留可点击导航 |
| 02 | [科幻 HUD：Arwes](https://arwes.dev/docs) | 青蓝网格、角框、仪表式分区 | 扫描、边框绘制、雷达、面板装配 | 中高；适合首页和项目；正文降低装饰 |
| 03 | [工程作品集：Brittany Chiang](https://brittanychiang.com/) | 深蓝底、青色强调、左侧个人身份、右侧履历内容 | 指针光场、导航定位、卡片聚焦、滚动编排 | 低中；最适合求职、学术和长文 |
| 04 | [复古桌面：98.js](https://98.js.org/) | Windows 98 风格窗口、桌面图标、任务栏 | 窗口开关、最小化、拖动、菜单展开 | 中高；个性强，手机需另做窗口布局 |
| 05 | [游戏地图：Bruno Simon](https://bruno-simon.com/) | 模块成为空间中的地点，主视图为探索场景 | 驾驶、相机、场景物体交互 | 很高；建议仅首页局部互动，不让找简历依赖游戏 |
| 06 | [横版游戏履历：Robby Leonardi](https://www.rleonardi.com/interactive-resume/) | 像素角色与关卡式经历 | 滚动驱动角色、场景视差、技能进度展开 | 高；视觉记忆强，长文仍用标准页面 |
| 07 | [沉浸式 3D：Lusion](https://lusion.co/) | 大尺度几何、空间深度、视觉实验作品区 | 粒子、几何变形、指针响应、镜头转场 | 很高；适合项目展示，显卡与载入成本最高 |
| 08 | [精密软件界面：Linear](https://linear.app/) | 精细边线、工作区面板、清晰信息层级 | 面板切换、卡片编排、光影、交互反馈 | 中；专业感强，可与 HUD 混合 |
| 09 | [工业仪器：teenage engineering](https://teenage.engineering/) | 奶白/灰底、橙色控制件、机械式网格 | 旋钮、刻度、机械按钮、模块展开 | 中；浅色 geek 路线，区分于常见霓虹黑底 |
| 10 | [研发实验室：GitHub Next](https://githubnext.com/) | 实验目录、项目入口、技术研究展示 | 实验节点连线、项目悬停预览、版面切换 | 中；与你的项目和学术成果结构契合 |

建议优先看 02、03、09。可以混合 03 的正文结构与 02 的首页动画。

## 来源核验限制

搜索工具读取了 Brittany、M4TT72、Bruno、Lusion、Linear、98.js、teenage engineering 和 GitHub Next 的页面。M4TT72 和 98.js 为脚本应用，静态抽取内容有限。Arwes 首页读取超时，但官方文档搜索确认了科幻界面、动画与音效定位。Robby 页面读取超时，其官方域名搜索可找到履历资料；未完成本轮动态页面视觉核验。所有参考动画都应通过原站亲自体验再决定。
