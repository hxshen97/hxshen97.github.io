# 需求与验收

## 原始需求

需求：重构个人主页，优化主页UI设计，增加动画效果，要求参考DESIGN.md中的Apple风格

## 范围与合理假设

- 本次重点是中英文首页及其共享组件，保留 Astro 静态架构和现有侧栏；其他模块保持已有内容与行为。
- 按 DESIGN.md 使用黑白 / 浅灰分区、紧凑标题、宽松留白、蓝色交互和胶囊按钮，不新增背景渐变或虚构个人文案。
- 动画采用原生 CSS 和 IntersectionObserver，无新增依赖；减少动态效果和无 JavaScript 时内容可读。
- 博客没有文章时展示双语空状态，保留新增 Markdown 的能力。
- docs/templates/requirements.md 中“保留简历下载”是过时模板文字，遵守 AGENTS.md 的网页简历不提供下载、旧 PDF 返回 404。

## 验收标准

| 编号 | 用户可观察结果 | 验证方式 |
| --- | --- | --- |
| R1 | 两种语言使用一致的 Apple 风格布局，姓名、头像、身份保留 | 桌面 / 移动截图与浏览器检查 |
| R2 | 入场和滚动动画可用，减少动态效果 / 无 JS 可读 | 新增浏览器测试 |

| R4 | 内容、资源、草稿过滤、公式、双语路由完整 | 既有完整验收 |

六个模块、双语路由与详情 slug、Markdown、头像、真实个人信息、邮箱 hxshen_fdu@outlook.com；CV 不提供 PDF 下载。保留精选项目最多 3 个、论文按年排序最多 2 个、非草稿文章按日期排序最多 4 个的首页规则。
