# 实施方案

## 问题与目标行为

中英文首页重复维护整页，空博客区隐藏，现有宽度与连续白色区块缺乏 DESIGN.md 的层次。抽取一份共享主页，形成个人介绍、精选项目、学术成果、博客、联系的阅读顺序。

## 模块与数据变化

- src/components/HomePage.astro 显式接收 lang，集中读取集合并复用现有卡片；路由作为薄入口。
- SidebarLayout 增加可选首页展示模式，放宽首页内容画布；默认布局不变。
- 首页专属样式负责黑色介绍区、浅灰项目区、白色论文区、浅灰文章区与黑色联系区，卡片不强加悬浮变换。
- 所有新增 UI 文本维护 en / zh 字典，链接使用 localizedPath。保留内容字段与 schema，不改 Markdown 和头像。
- 一次性滚动渐入使用 Web Animations API 与 IntersectionObserver；内容默认可见，不依赖初始化类隐藏内容。系统减少动态效果时不执行动画，动态切换时取消正在执行的动画。
- 共享全局补充可见焦点和减少动态效果支持，菜单保持既有交互。

## 实施步骤

1. 需求与方案记录；创建 codex/ 分支。
2. 抽取共享主页、双语文案和首页布局，新增动画及主页浏览器测试。
3. 完整本地验收、截图审查、单独模型只读审查，记录证据。
4. 提交并创建 PR；涉及 AGENTS.md 控制文件更新，保持 Draft 供基础设施审查，不自动合入。

## 验证与风险

运行 npm run verify；额外验证动画、无 JS、减弱动态效果与 360px 窄屏。系统 SF 字体不可用时使用现有字体回退，不下载专有字体。共享 Markdown 正文不声称已经翻译。Node 本地运行版本需核对，无法使用固定版本时记录差异。

回退此 PR；无内容或数据迁移，无新增依赖和路由变化。
